# Asian Delight 🍜

A responsive restaurant landing page concept showcasing Asian cuisine. This project was built with HTML, CSS, and vanilla JavaScript.

## Features

- Restaurant landing page with hero, about, popular dishes, trending food and drinks, newsletter, and footer sections
- Responsive navigation with a mobile menu
- Menu category filters for browsing dishes
- Scroll-reveal animations powered by [AOS](https://michalsnik.github.io/aos/)
- Smooth scrolling between page sections
- Image fallback placeholders for selected food images
- Custom SVG interface and social icons

## Built With

- HTML5
- CSS3 (Flexbox, Grid, responsive media queries, CSS custom properties)
- Vanilla JavaScript
- AOS (Animate On Scroll)
- Google Fonts: Playfair Display and Plus Jakarta Sans

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

For the best development experience, open the folder in Visual Studio Code and use the Live Server extension.

## Notes

- The page uses externally hosted food and avatar images, Google Fonts, and the AOS CDN, so an internet connection is needed for all visual assets and animations to load.
- The newsletter form currently demonstrates a front-end confirmation only. It does not send or store email addresses because no backend or mailing-list service is connected.
- The restaurant content and menu are sample content for a frontend portfolio project.
